# @panchnama/web

Next.js (App Router) public scorecard application: static audit pages plus
a small server-side API for anonymous experience submissions and approved-
experience reads (implementation.md sections 4.1 and 10).

**Status:** scaffold only — a placeholder home page and layout. The runtime
shell is extended in Session 10 ("Application runtime, anonymous experience
API, and abuse controls") and the visual scorecard is built starting
Session 11 ("Frontend foundation and design system").

## Local development

```bash
pnpm --filter @panchnama/web dev
```
